# Wujie Vue 3 Sub-Application

---

## 💡 概述

A Vue CLI project serving as a Vue 3 sub-application example for the wujie micro-frontend framework.

---

## ⚡ 功能

- Development server with hot-reload
- Production build with minification
- Linting and auto-fix support
- Customizable Vue CLI configuration
